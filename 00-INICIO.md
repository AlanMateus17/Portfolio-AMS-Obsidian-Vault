## ⚙️ Configuração recomendada do Obsidian (tudo gratuito)

1. **Configurações → Arquivos e links → New link format:** deixe como "Shortest path possible" (já é o padrão) — assim os links `[[assim]]` funcionam mesmo com arquivo em pasta diferente
2. **Ativar o core plugin "Backlinks"** (Configurações → Plugins principais) — já vem ativado por padrão, mostra quem linka pra cada nota
3. **Graph View** (ícone de rede na barra lateral esquerda) — visualiza o portfólio inteiro conectado, bom pra "ver o todo" sem ler tudo
4. **Opcional, plugin de comunidade gratuito "Dataview"** — se quiser depois, permite montar uma tabela automática tipo "todos os sistemas com status: completo" — não é necessário, é só um extra se você gostar de automatizar
