Sistemas operacionais

Arch, Kali e os outros: sim, mas do jeito certo

Você deve aprender Arch e Kali. O que eu desaconselhei foi o jeito: particionar o SSD atual em dual boot agora. O risco é perder dados de novo e travar o setup que já funciona. Com o segundo NVMe e máquinas virtuais, você tem todos os sistemas sem esse risco.

O Windows 11 Home não tem o Hyper-V Manager. As VMs rodam no VirtualBox (grátis, inclusive para uso comercial) ou no VMware Workstation Pro (grátis só para uso pessoal). Os dois funcionam com o WSL2 ligado, mas ficam um pouco mais lentos, porque usam a plataforma de hipervisor do Windows. Com 32 GB de RAM, rode no máximo uma ou duas VMs por vez.
