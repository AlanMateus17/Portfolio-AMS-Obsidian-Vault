# Instituto AMS Silva

**Cursos, exercícios e materiais para quem aprende e para quem ensina tecnologia.**

## Para quem é

Quem está começando em programação, estudantes de cursos técnicos, concurseiros de TI e professores.

## O problema

Quem começa em programação trava na lógica, estuda por vídeos soltos sem ordem e não tem como saber se aprendeu de verdade; o professor passa as noites montando aula e preenchendo documento.

## Como resolvemos

### Trilha Lógica

Aprender lógica de programação do zero, com explicação, exercícios corrigidos, revisão espaçada e simulados no estilo dos concursos.

| Pacote | O que inclui |
|---|---|
| Mini-curso | as aulas de lógica |
| Mini-curso + exercícios | as aulas e o banco de exercícios com correção |
| Completo | aulas, exercícios, baralhos Anki e simulados |

### Formações

Um caminho inteiro e organizado, disciplina por disciplina, em vez de cursos soltos.

| Pacote | O que inclui |
|---|---|
| Disciplina avulsa | uma disciplina |
| Formação | a formação inteira |
| Assinatura | todas as formações e a comunidade |

*Situação: onda 3.*

### Para professores

Aula pronta e documento escolar preenchido e conferido, para o professor recuperar as noites.

| Pacote | O que inclui |
|---|---|
| Professor | aulas prontas e fábrica de documentos |
| Escola | o pacote professor para toda a equipe |

*Situação: onda 2.*

### Catálogo do HTML (gratuito)

Criar e publicar o primeiro site com HTML, CSS e JavaScript, de graça: é a porta de entrada dos alunos.

### Sob demanda

Aula particular e workshop sob medida.

| Pacote | O que inclui |
|---|---|
| Aula avulsa | uma aula |
| Pacote de aulas | aulas por mês |
