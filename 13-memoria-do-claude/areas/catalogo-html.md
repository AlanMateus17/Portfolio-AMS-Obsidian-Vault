- [stated] Mantém o repositório AlanMateus17/catalogo-html com o "Catálogo do HTML", site de referência que usa para ensinar HTML, CSS e JavaScript aos alunos
- [stated] Quer que os alunos usem o site para criar os próprios sites do zero, subir o repositório no GitHub e publicar no GitHub Pages pelo terminal, com passo a passo no formato Confira / Erro comum / Você tenta / Pronto quando
- [stated] Quer que o site tenha documentação completa e didática (sintaxe, semântica e cada ferramenta: bibliotecas, criação de API etc.) para construir um sistema completo, seguindo a própria stack tecnológica dele, para ele mesmo estudar no processo; decidiu entregar por módulos, validando cada um com a turma
- [stated] Quer que o Catálogo cubra o que precisa estudar para a primeira vaga fullstack e trabalhe junto com o AM Mentor, sem abandonar nenhum dos dois
- [stated] Quer no site uma seção ensinando aos alunos onde usar IA (para escrever código e outras funções) e onde não usar, porque nesses casos a IA os prejudica e não entrega conhecimento, habilidade nem agilidade
- [stated] Quer vender o site em plataformas de infoproduto; está considerando cerca de R$ 300 em pagamento único, mensalidade ou plano anual, e acrescentar o desenvolvimento de projetos para agregar valor à assinatura
- [stated] Quer incluir na formação 12 projetos ligados aos sistemas AM que ele já tem para desenvolver; não entrega os projetos completos, só condições para o aluno fazer do zero e o resultado final esperado
- [stated] Quer gerar renda extra com a venda do curso, mirando R$ 10 mil por mês e com possibilidade de escalar
- [stated] Quer que o próprio site tenha área de administrador, cadastro/login de usuários, tipos de usuário com autorizações e liberação de planos de assinatura e venda de produtos, com controle total e passando segurança para o comprador; escolheu construir isso na própria stack (.NET + PostgreSQL) e vender por todos os canais possíveis
- [stated] Quer que os alunos vejam online os códigos gratuitos (trilha Passo a passo e capítulo de HTML); em out/2026 decidiu que não quer mais desenvolver o site para o GitHub Pages (antes planejava uma versão pública gratuita lá)
- [stated] Incomodado com páginas estáticas repetindo cabeçalho/botões; quer reaproveitar código com uma organização melhor; quer conteúdo grátis e pago juntos numa plataforma só, com as melhores práticas e tecnologias de mercado
- [stated] Quer que outros professores, de qualquer área, também ofereçam os próprios cursos na plataforma dele, em dois modos: estilo Udemy/Rocketseat e uma versão mais personalizada para cada professor e seus alunos (ex.: curso de artes não se mistura com física básica); quer a plataforma organizada, fácil de usar e com UX profissional, e quer definir todas as funcionalidades para começar a desenvolver do zero
- [stated] A ideia da plataforma é os alunos estudarem praticamente sozinhos
- [stated] Quer videoaulas na plataforma no formato Udemy/Rocketseat/Alura; going with começar guardando os vídeos no próprio servidor (custo zero) e depois migrar para o Bunny Stream
- [stated] Quer também vender a própria plataforma personalizada com a marca do cliente e só os recursos que ele pagar; decidiu vender de duas formas: assinatura (escola dentro da plataforma dele) e servidor exclusivo com mensalidade de manutenção; quer que o cliente consiga montar o site do jeito que quiser
- [stated] Quer que o nome da plataforma siga a família "AM" do portfólio, mas não sabe se "Saberia" causa boa impressão para clientes e recrutadores
