# Badge

Selo curto que mostra estado ou fase, sempre com texto, nunca só cor.

- **Sucesso** (`aura-badge--success`): instalado, pago, aprovado.
- **Atenção** (`aura-badge--warning`): pendente, nesta semana, aguardando.
- **Perigo** (`aura-badge--danger`): erro, vencido, decisão pendente.
- **Marca** (`aura-badge--brand`): fase ou categoria neutra da Aura.
- **Neutro** (`aura-badge--neutral`): futuro, rascunho, arquivado.

Texto em IBM Plex Mono 11px, `radius-sm`. Use rótulos de uma ou duas palavras ("Pago", "F1", "Futuro").

Quem usa fornece: o texto do selo e a escolha do estado.
