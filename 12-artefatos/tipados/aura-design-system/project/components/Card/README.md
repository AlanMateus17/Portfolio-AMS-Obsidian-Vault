# Card

Agrupa um assunto: um produto, um sistema, uma camada do diagrama, um item de plano.

Estrutura: rótulo opcional (`aura-card__eyebrow`, mono maiúsculo em `gold-ink`), título (`aura-card__title`), texto de apoio (`aura-card__body` em `muted`) e, se precisar, selos e botões no fim. Fundo `surface`, borda `line`, `radius-lg`, padding `space-4`, sem sombra.

Cartões lado a lado têm as mesmas bordas, a mesma ordem de elementos e o mesmo padding. Use o cartão para separar um objeto; não envolva a página inteira em cartões.

Quem usa fornece: o conteúdo, a quantidade de colunas da grade e a ação, se houver.
