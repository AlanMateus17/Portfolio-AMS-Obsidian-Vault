1. Como conectar HTML, CSS e JavaScript

O HTML é o arquivo principal. É ele que "chama" os outros dois, com duas linhas dentro do <head>.

A estrutura de pastas

pagina-completa/
├── index.html      ← você abre este
├── sobre.html
├── css/
│   └── estilo.css
├── js/
│   └── script.js
├── img/            ← fotos
├── midia/          ← vídeo, áudio, legendas
└── docs/           ← PDF para download

Os caminhos (href e src) são relativos: partem da pasta onde está o arquivo HTML. css/estilo.css quer dizer "entre na pasta css e pegue estilo.css".

As duas linhas de conexão

<head>
  <meta charset="UTF-8">
  <title>Minha página</title>

  <!-- CSS: no head, antes de desenhar -->
  <link rel="stylesheet" href="css/estilo.css">

  <!-- JS: defer = roda depois do HTML -->
  <script src="js/script.js" defer></script>
</head>

Erros que quase todo mundo comete

  • Caminho errado. href="estilo.css" quando o arquivo está dentro da pasta css. A página abre sem estilo e só o F12 mostra o erro 404.
  • Maiúscula e minúscula. No Windows, Estilo.css e estilo.css funcionam igual. Quando o site vai para a internet (servidor Linux), não. Use sempre minúsculas e sem acentos nos nomes de arquivos.
  • Script sem defer no head. O JavaScript roda antes dos botões existirem e dá Cannot read properties of null.
  • Esquecer o </script>. A tag de script nunca fecha sozinha.
  • Cache. Mudou o CSS e nada aconteceu? Aperte Ctrl + F5 para recarregar sem usar a cópia guardada.
Como conferir se conectou: aperte F12, abra a aba Rede (Network) e recarregue a página. Aparecem estilo.css e script.js com status 200 (encontrado). Se aparecer 404, o caminho está errado. Abrindo pelo Live Server do VS Code, a lista fica completa.

Parágrafos e marcações dentro do texto

Este é um parágrafo. Dentro dele posso ter texto importante (strong: importância, aparece em negrito), texto com ênfase (em: ênfase na fala, aparece em itálico), texto marcado (mark: marca-texto), letras miúdas (small: observações e direitos autorais), texto apagado e texto inserido (del/ins: correções), H2O (sub: subscrito) e 102 (sup: sobrescrito).

Também existem b (negrito sem importância), i (itálico, ex.: Homo sapiens) e u (sublinhado; evite, parece link).
A tag <br> que está no código acima quebrou esta linha sem criar outro parágrafo. Use br só em poemas e endereços, e nunca para dar espaço: espaço é trabalho do CSS.

Imagem como link

Link ou botão? Se ele leva a outro lugar (página, seção, arquivo), é <a>. Se ele faz alguma coisa na página (abrir menu, somar, trocar tema), é <button>. A aparência não importa: o CSS pode deixar um parecido com o outro.

O que é HTML?

É a linguagem de marcação que dá estrutura à página: diz o que é título, parágrafo, imagem, link.

HTML é linguagem de programação?

Não. HTML não tem variáveis, decisões nem repetições. É uma linguagem de marcação. A programação da página fica com o JavaScript.

Preciso decorar todas as tags?

Não. Você precisa saber que elas existem e onde consultar. Os programadores consultam a documentação o tempo todo.

Divisões genéricas: <div>

A div é uma caixa sem significado. Use quando nenhuma tag semântica serve e você só precisa agrupar coisas para o CSS, como as colunas desta página. Primeiro pergunte: "é um header? um article? uma section?". Se não for nada disso, aí sim é div.
