Sistema de ponto de venda multi-tenant. Isolamento de dados por Row-Level Security no PostgreSQL, API em Clean Architecture, frontend em Next.js.

ESPECIFICAÇÕES

Backend.NET 10 · ASP.NET Core
Banco de dadosPostgreSQL + RLS
Cache / filaRedis
Tempo realSignalR
FrontendNext.js · TypeScript
ArquiteturaClean Architecture + DDD
Modelo de tenanttenant_id + RLS

DIAGRAMA INTERNO

FUNCIONALIDADES (PINOUT)

  • 01Cadastro de produtos, categorias e variações por tenant
  • 02Frente de caixa com atalhos de teclado e leitor de código de barras
  • 03Controle de estoque com baixa automática na venda
  • 04Isolamento total de dados entre lojas via RLS no PostgreSQL
  • 05Emissão fiscal via interface plugável (IEmissorFiscal)

DECISÕES DE ARQUITETURA

  • →RLS em vez de schema-per-tenant: menos overhead operacional pra escalar até centenas de lojas
  • →Clean Architecture: troca de banco/fiscal sem reescrever regra de negócio
  • →SignalR: dashboard de vendas atualiza em tempo real sem polling
